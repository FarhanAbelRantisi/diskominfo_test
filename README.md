# Diskominfo Test - Pusat Aduan Layanan Publik

### Cara Menggunakan
- download dan install file diskominfo.apk pada link dibawah menggunakan perangkat android atau emulator

### Fitur
- Halaman login dan register menggunakan firebase authentication
- Navigasi antar halaman menggunakan bottom navigation bar
- Data yang ditampilkan dinamis berdasarkan email user yang login (firebase realtimedatabase)
